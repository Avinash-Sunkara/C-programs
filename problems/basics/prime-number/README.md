# Prime number

## Problem

Read an integer and determine whether it is prime. Values below 2 are not prime.

## Example

Input:

```text
29
```

Output:

```text
Prime
```

## Approach

Test possible divisors up to the square root of the number.

## Complexity

O(?N).

## Compile and run

From this folder, compile using `gcc -std=c11 -Wall -Wextra -pedantic prime_number.c -o prime_number`. Run the executable and provide input in the format above. The solution uses standard input and output.
