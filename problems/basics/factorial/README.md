# Factorial

## Problem

Read N from 0 through 20 and print N factorial.

## Example

Input:

```text
5
```

Output:

```text
120
```

## Approach

Multiply every integer from 2 through N.

## Complexity

O(N).

## Compile and run

From this folder, compile using `gcc -std=c11 -Wall -Wextra -pedantic factorial.c -o factorial`. Run the executable and provide input in the format above. The solution uses standard input and output.
