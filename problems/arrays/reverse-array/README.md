# Reverse an array

## Problem

Read N (1..1000) integers and print them in reverse order.

## Example

Input:

```text
4
2 4 6 8
```

Output:

```text
8 6 4 2
```

## Approach

Store the values, then print from the final index to zero.

## Complexity

O(N) time and storage.

## Compile and run

From this folder, compile using `gcc -std=c11 -Wall -Wextra -pedantic reverse_array.c -o reverse_array`. Run the executable and provide input in the format above. The solution uses standard input and output.
