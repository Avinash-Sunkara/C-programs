# Reverse a string

## Problem

Read a line of up to 999 characters and print it reversed.

## Example

Input:

```text
hello C
```

Output:

```text
C olleh
```

## Approach

Find the line length and swap characters from the two ends inward.

## Complexity

O(N) time, O(1) extra space.

## Compile and run

From this folder, compile using `gcc -std=c11 -Wall -Wextra -pedantic reverse_string.c -o reverse_string`. Run the executable and provide input in the format above. The solution uses standard input and output.
