# Problems

Exercises are grouped by topic. Each exercise folder contains a problem-specific `README.md` and one or more C solutions.

## Topics

- [`loops/`](loops/): repetition and counting exercises.
- [`basics/`](basics/): arithmetic, number properties, and sequences.
- [`arrays/`](arrays/): traversal, searching, sorting, and pair problems.
- [`strings/`](strings/): string reversal and palindrome checks.
- [`recursion/`](recursion/): recursive problem solving.
- [`pointers/`](pointers/): pointer fundamentals.
- [`bit-manipulation/`](bit-manipulation/): binary and bitwise operations.
- [`data-structures/`](data-structures/): linked list exercises.
